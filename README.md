# XML Validator

[![Deploy to GitHub Pages](https://github.com/V291111893SA/xml-validator/actions/workflows/deploy.yml/badge.svg)](https://github.com/V291111893SA/xml-validator/actions/workflows/deploy.yml)

Веб-приложение для валидации XML файлов контрактов финансовой аренды.

## Возможности

- ✅ Проверка синтаксиса XML
- ✅ Валидация обязательных полей
- ✅ Проверка форматов дат (YYYY-MM-DD и ISO 8601)
- ✅ Валидация числовых значений
- ✅ Проверка валют (BYN, USD, EUR, RUB)
- ✅ Валидация структуры schedule и payments элементов
- ✅ Предупреждения о потенциальных проблемах

## Использование

1. Откройте [веб-приложение](https://V291111893SA.github.io/xml-validator)
2. Загрузите XML файл (перетащите или выберите)
3. Получите результат валидации

## Развертывание

Проект автоматически развертывается на GitHub Pages при пуше в `main` ветку через GitHub Actions.
